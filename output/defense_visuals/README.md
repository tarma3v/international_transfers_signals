# Графики для защиты

`temperature_example.png` — зафиксированный пользователем пример температуры.
Все предыдущие варианты сохранены рядом, включая инверсию `100 − температура`
и другие границы дат. Их исходные пиксели не изменялись при сборке презентации.

`chart_evidence.json` содержит источники и численные показатели.
`research/build_defense_visuals.py` строит графики из сохранённых AP37/AP50.

Важная оговорка к старым подписям «OOS»: прогнозы получены последовательно,
но этот период уже использовался для исследования и выбора моделей. Поэтому
это **открытая ретроспектива, а не новый независимый holdout**.
Красивый фрагмент выбран вручную. Его попадания не являются оценкой качества
на всём периоде. Температура — внутренняя вероятность, а не клиентский индикатор.

В презентации общий lift показан как 2,492 = 73,38 % / 29,45 %.
Число 2,51 в подписи сохранённого графика — округлённый adjusted lift 2,509188
с другой агрегацией базы сравнения, не новый результат.
