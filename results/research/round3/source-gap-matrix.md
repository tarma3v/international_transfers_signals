# Source-gap matrix

| Тема | Что подтверждено | Что остаётся неизвестным | Влияние |
|---|---|---|---|
| ЦБ timestamp | официальный ориентир времени публикации | нет исторического машинного timestamp каждой публикации | after-publication policy требует runtime gate |
| Клиентский курс | есть официальный курс ЦБ | нет банковского спреда и доступного клиенту execution price | нельзя заявлять реальную денежную прибыль |
| Поведение клиента | target отражает хороший день | нет conversion/uplift эксперимента уведомлений | нет доказанной бизнес-модели |
| Режим 2022 | статистическая смена видна в рядах | нет каузальной идентификации санкций/SWIFT | формулировать только как regime break |
| Новый holdout | locked anchor был зафиксирован заранее | 2024-2026 просмотрен для round-2/3 идей | новые лидеры только retrospective |
| Multiple testing | 157 recorded policies вошли в max-shift audit | это диагностический analog, не полный formal SPA | не заявлять 5% superiority |
| Сезонность | train-only анализ и перенос по блокам проверены | мало независимых годовых циклов после break | сезонные фичи только слабые auxiliaries |
| Валюты | пять коридоров оценены вместе и отдельно | нет данных спроса/объёма по коридорам | macro/corridor average не равен бизнес-weighted KPI |
