# Финальные шаблоны уведомлений и проверка фактов

Прогнозная модель выбирает повод для проверки сообщения. Сам текст описывает
настоящее или прошлое. Температура и вероятность будущего клиенту не сообщаются.
Все величины в фигурных скобках вычисляются, не подставляются произвольно.

| Сценарий | Что обязано быть истинно | Пример шаблона |
| --- | --- | --- |
| Падение курса | нужное число последовательных снижений на доступном ряду | «Курс {валюты} снижается {N}-ю публикацию подряд. Курс ЦБ на {дата}.» |
| Уровень относительно прошлого | отдельно рассчитанная доля прошлых дней, а не вероятность модели | «Курс {валюты} ниже, чем в {P} % дней за последние три месяца. Данные ЦБ на {дата}.» |
| Изменение за неделю | вычисленная величина с правильным знаком для клиента | «За неделю рубль укрепился к {валюта} на {X} % по ЦБ. Данные на {дата}.» |
| Отскок от минимума | установленный рост после наблюдённого минимума | «После минимума {дата1} курс {валюты} вырос на {X} % по ЦБ. Данные на {дата2}.» |
| Собственный уровень | пользователь задал порог, актуальная котировка его достигла | «Ваш уровень достигнут: за {R} ₽ получатель получит {F} {валюта}. Условия на {время}.» |
| Позднее открытие | сумма изменилась; есть свежая котировка и контекст старого сообщения | «Условия обновились. Сейчас получатель получит {F}. В уведомлении было {F_old} на {дата_old}.» |
| Праздник | релевантный календарный повод, без выдуманного прогноза | «{Поздравление}. Актуальные условия перевода близким доступны в приложении.» |
| Источник отсутствует | актуальную цену проверить нельзя | модельный пуш не отправляется |
| Сильная модель, но нет допустимого факта | высокий скор не доказывает ни один исторический текст | модельный пуш пропускается |

Направление «курс растёт» само по себе не разрешает писать «окно закрывается»
как обещание дальнейшего движения. Публикации нельзя без проверки называть
календарными днями. Исторический диапазон и процентиль — тоже разные формулы.

## Что запрещаем в подготовленном наборе

| Формулировка | Почему исключена |
| --- | --- |
| «Курс завтра вырастет» | утверждение о будущем |
| «Успейте, пока не подорожало» | косвенное обещание будущего роста |
| «Гарантируем лучший курс» | неподтверждённая гарантия и сравнение |
| «Заработайте на курсе» | обещание торговой прибыли вне задачи |
| «Температура 85, значит перевод выгоден» | вероятность не равна гарантии результата |
| «По ЦБ вам гарантированно придёт…» | официальный курс не равен банковской котировке |
| «Ждать чаще не помогало» как автоматическое обоснование | может читаться как прогноз через историческую аналогию; заменяем проверяемым фактом редкости |

## Проверка перед пилотом

Проверить знак курса, номинал, окно, даты и источник. Для суммы использовать
котировку банка и комиссию. Учесть падеж валюты, язык, местное время и
значимость праздника. Согласовать конкретные тексты с банком.

Ранняя библиотека из 100 вариантов остаётся в main как материал работы,
а не как автоматически одобренный набор для финальной модели:
