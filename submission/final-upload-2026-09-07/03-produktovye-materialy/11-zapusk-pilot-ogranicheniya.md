# Запуск, пилот и ограничения

## 1. Воспроизведение

Итоговый код находится в ветке `ivan-experiments`, а не только в `main`:
https://github.com/tarma3v/international_transfers_signals/tree/ivan-experiments

Python-зависимости перечислены в `requirements.txt`. Для исторического входа:

```bash
python run_final_temperature.py --as-of 2026-09-01T15:45:00+03:00 --currency KZT
python run_final_temperature.py --as-of 2026-09-01T18:45:00+03:00 --currency KZT --verified-receipt-at 2026-09-01T18:42:00+03:00
python -m pytest tests/test_final_temperature_model.py
```

Это воспроизведение сохранённых исторических расчётов. Параметр receipt в
примере демонстрирует контракт, а не подтверждает реальный журнал публикации
1 сентября. Нельзя поставить произвольную дату и объявить её фактом получения.

Основные файлы: `model/final_temperature_model_v1.json`, `run_final_temperature.py`,
`results/research/after_publication/ap37_effective/retrospective_all_horizons.csv`,
`results/research/final_case_metric_matrix.csv`. Манифест хранит хеши результатов.
Исследовательские скрипты сохранены в `research/`; короткий вход не обучает
весь ансамбль заново и не является готовым подключением к живым биржевым данным.

## 2. План пилота

Сначала собираем новые котировки и реальное время их получения, фиксируем
модель и правило отбора до оценки нового периода. Проверяем, сохраняется ли
полезность относительно банковского курса с комиссией, а не только ЦБ.

Далее клиентский пилот: случайное распределение клиентов в контрольную группу
и группу продукта, постоянное назначение группы, одинаковые допустимые условия
коммуникации. Основная метрика — дополнительный net-объём переводов.
Отдельно проверяем сдвиг будущих переводов, а не считаем любой ранний перевод
новым. Нужны защитные метрики отписок, жалоб и нежелательных контактов.

Число клиентов и продолжительность нельзя честно назначить из модельного lift.
Для них требуются базовая конверсия, дисперсия объёма, повторные действия,
минимальный значимый бизнес-эффект и лимит контактов банка. В старом `main`
есть расчёты для прежнего редкого правила; они не являются расчётом мощности
пилота AP37 и сюда не перенесены.

## 3. Что нужно подключить

- данные ЦБ/MOEX с временем получения и контроль опоздавших источников;
- актуальный курс перевода, комиссию и срок действия котировки;
- общий лимит пользователя, согласия и местное время;
- проверку исторического факта для текста;
- контрольную группу и измерение результата по клиентам.

## 4. Что нельзя обещать

Ретроспективный lift 2,492 не доказывает такой же результат в будущем.
Вечернее знание нового курса не означает возможность купить по старому курсу
банка. Средняя частота 1,038 на валюту не является частотой реальной доставки
после всех клиентских фильтров. Макеты не являются встроенной функцией банка.
