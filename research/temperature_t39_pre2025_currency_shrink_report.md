# T39: валютная усадка из pre-2025 не улучшила локальную устойчивость

## Короткий вывод

T39 проверил ближайший допустимый после T38 шаг: выбрать отдельную силу
history-поправки для каждой валюты только на ранних OOS-прогнозах, не читая ни
одного target 2025-2026. Итоговый кандидат улучшил pooled Brier и AUC и прошёл
40/40 общих `scenario x clock` проверок относительно T37, но ухудшил строгую
локальную картину:

| Аудит | T37 | T39 |
|---|---:|---:|
| Clock-local pass | **619 / 680** | 594 / 680 |
| Pooled local pass | **25 / 34** | 22 / 34 |
| Pooled year pass | **4 / 4** | 3 / 4 |

`retrospective_repair_passed=false`, `production_promoted=false`. T37 остаётся
frozen h20 shadow без изменения.

## Как выбор был отделён от открытого периода

Для каждой валюты использованы 226 зрелых OOS-строк 2023 как screen и 228
зрелых OOS-строк 2024 как validation. На 2023 выбирался один из пяти заранее
зарегистрированных весов `0 / 0,25 / 0,5 / 0,75 / 1` по минимуму Brier. На 2024
выбранный вес мог только пройти gate или откатиться к фиксированному T37-весу
0,5. Validation не выбирала другой ненулевой вариант.

| Валюта | Выбор 2023 | Gate 2024 | Frozen alpha |
|---|---:|---:|---:|
| AMD | 1,0 | PASS | 1,0 |
| KGS | 1,0 | FAIL: ECE +0,0310 | 0,5 |
| KZT | 1,0 | FAIL: AUC -0,0126 | 0,5 |
| TJS | 1,0 | FAIL: ECE +0,01031 | 0,5 |
| UZS | 1,0 | PASS | 1,0 |

Только после фиксации этой карты был один раз открыт диагностический
2025-2026. Поэтому T39 не является подгонкой под TJS из T38. Более того,
TJS остался на прежнем alpha=0,5: ранние данные сами запретили усиление.

## Почему aggregate выглядит привлекательным

Относительно T37 alpha=1 для AMD/UZS улучшил оба pooled receipt-сценария:

| Сценарий | Δ Brier | Δ log-loss | Δ AUC | Δ ECE |
|---|---:|---:|---:|---:|
| Calendar receipt replay | -0,000719 | -0,002565 | +0,02043 | +0,000250 |
| No same-day receipt | -0,000776 | -0,002764 | +0,02193 | +0,000278 |

Все 40 общих clock-состояний non-inferior. Если смотреть только на средний
Brier/AUC, T39 кажется улучшением. Однако виджет показывает вероятность по
конкретной валюте, поэтому pooled-метрика недостаточна.

## Где перенос сломался

На открытом периоде появились 25 новых clock-local failures:

- 17 строк `AMD:2026`;
- 7 строк UZS;
- 1 объединённая строка 2026.

Также потеряны три ранее проходившие pooled группы:

- calendar `AMD:2026`;
- calendar `UZS:2026`;
- no-receipt `year=2026`.

Для `AMD:2026` календарный point Brier улучшается на -0,00798 и AUC растёт на
+0,14270, но ECE ухудшается на +0,02115, а Brier CI сверху пересекает ноль.
То есть усиленный эксперт хорошо ранжирует, но его числу 0-100 нельзя приписать
достаточно стабильный вероятностный смысл в этом локальном режиме.

## Что это говорит о данных

2023 предпочитает максимальную силу history-эксперта для всех пяти валют. Уже
2024 отвергает эту силу для трёх валют по разным причинам, а 2026 ломает часть
двух оставшихся разрешений. Значит, двух ранних лет недостаточно, чтобы считать
currency-specific alpha стабильной структурной константой. Это согласуется с
предыдущими результатами о regime drift и не поддерживает ещё более детальную
`валюта x режим` карту на том же материале.

## Решение

T39 не включается ни в runtime, ни в push, ни в temperature output. Сохраняем:

- T37 как единый source-driven h20 prospective shadow;
- T38 как обязательное предупреждение о currency-local calibration;
- alpha=0,5 для всех history-строк;
- точный T19 на market/bridge/hold и T22 только после verified receipt.

Следующий честный путь должен добавлять независимую информацию, а не дробить
две pre-2025 выборки ещё сильнее: prospective outcomes с фактическими receipt
timestamps, более длинный OOS replay тех же intraday source states или
иерархическая калибровка с заранее заданной сильной усадкой к общему уровню.

Полный пакет, frozen map, 204 bootstrap-интервала и audit:
`results/research/temperature/t39_pre2025_currency_shrink/`.
