# Прогноз выгодности перевода в любой момент

## Результат текущей итерации

Мы собрали единый причинный контур для пяти валют — AMD, KGS, KZT, TJS и UZS.
В любой момент запрос получает не старый дневной прогноз, а последний допустимый
снимок с явным временем источника. Главный экранный показатель — температура
0–100: калиброванная вероятность, что действующий курс ЦБ окажется не хуже
следующих `h` публикаций. Рядом возвращается отдельная оценка ожидаемой
future-only выгоды в базисных пунктах ЦБ.

| Что готово | Значение |
|---|---|
| Горизонты | 1, 3, 5, 10 и 20 следующих публикаций ЦБ |
| Ретроспектива | 2024–2026, 60 370 снимков «валюта × момент» |
| Время работы | утро, биржевая сессия, публикация нового ЦБ, вечер до 23:00, ночь и выходные |
| Выходы | температура, ожидаемые б.п., источник, свежесть, фаза, уверенность, отдельный `push_now` |
| Push | AP37, не более двух сигналов на валюту в ISO-неделю |
| Не доказано | точный исторический receipt ЦБ и реальная экономия по банковской котировке |

Температура и ожидаемые б.п. отвечают на разные вопросы. Температура — «какова
вероятность, что переводить сейчас удачно?». Б.п. — «насколько большим ожидается
преимущество, если оно есть?». Они имеют разные модели, метрики и provenance.

# Как это работает простыми словами

## Один ответ строится в четыре шага

1. Берём текущий действующий курс ЦБ и только те биржевые свечи, которые уже
   полностью завершились к моменту запроса.
2. Роутер определяет фазу дня и выбирает модель, честно доступную в этой фазе.
3. Для выбранного горизонта модель оценивает вероятность и ожидаемую разницу с
   будущими курсами ЦБ. Вероятность калибруется только на созревшем прошлом.
4. API отдаёт число 0–100, объяснение, источник и его возраст. Редкий push
   решается отдельно и не включается автоматически от высокой температуры.

Пример: температура 73 на `h=5` означает примерно 73% вероятности, что
действующий курс ЦБ не будет хуже минимума следующих пяти публикаций. Это не
означает «73% прибыли» и не гарантирует курс банка. `expected_future_cbr_bps_h`
показывает ожидаемый запас по официальному ряду ЦБ, а не рубли на счёте клиента.

Валидация chronological OOS: для даты `t` обучение видит только более ранние
метки, которые уже полностью созрели, плюс двухдневный embargo. Тесты портят
будущие свечи и цели и проверяют, что прошлый ответ не меняется. Так мы защищаем
систему от главной ошибки временных рядов — подглядывания вперёд.

# Какая модель отвечает в течение дня

## Фазовый роутер

| Момент по Москве | Доступная информация | Ответ модели |
|---|---|---|
| до 09:00 | история ЦБ и календарь | history-only fallback, limited confidence |
| 09:00–10:00 | завершённый час CNYRUBF | perpetual обновляет h1/h3; остальные горизонты остаются history-only |
| 10:00–10:30 | первая допустимая CNY-свеча | early market route при физическом наличии, иначе fallback |
| 10:30–15:30 | завершённые spot-свечи | market-prefix; качество растёт по мере накопления дня |
| 15:30–receipt | новые свечи 16:30/17:30 | bridge без знания завтрашнего курса ЦБ |
| после receipt | объявленный курс на завтра | AP50 вероятность + AP51 ожидаемая выгода |
| 19:00/20:00 | новые завершённые spot-свечи | T7B корректирует вероятность и ожидаемые б.п. |
| 20:00–23:00 | завершённые CNYRUBF/USDRUBF | T16 уточняет только ожидаемые h3/h5 б.п. |
| ночь/выходной | новых источников нет | последний снимок с aging и явным статусом stale |

Ключевой принцип: источник вероятности и источник ожидаемой выгоды могут быть
разными. Например, в 21:15 вероятность может честно оставаться от spot-снимка
20:00, а оценка h5-выгоды уже использовать perpetual-свечи 20:59:59. API
показывает оба timestamp, поэтому интерфейс не называет старый прогноз новым.

Исторически receipt пока считается календарно. В продуктиве переключение должно
происходить по реально полученному событию публикации ЦБ, а не по константе.

# Метрики температуры: насколько верить числу 0–100

## Вероятность на открытом периоде 2025–2026

| Фаза | AUC / Brier | Что это значит |
|---|---:|---|
| premarket h1/h3/h5 | AUC 0,594 / 0,604 / 0,596 | честный, но слабый fallback |
| 09:00 perpetual h1 | 0,753 / 0,2024 | против 0,587 / 0,2450 у history-only |
| 09:00 perpetual h3 | 0,734 / 0,1898 | против 0,586 / 0,2173 у history-only |
| 10:00 h5 | 0,730 / 0,1716 | первое сильное market-обновление |
| 10:30, среднее горизонтов | 0,757 / 0,1562 | рынок уже заметно помогает |
| 15:30, среднее горизонтов | 0,785 / 0,1477 | лучший пред-публикационный срез сетки |
| after-publication AP50 h3/h5/h10/h20 | Brier 0,165 / 0,163 / 0,164 / 0,133 | хорошо откалиброванный виджет |
| 19:00 T7B, среднее | 0,716 / 0,1492 | небольшой плюс новой spot-свечи |

AUC больше — лучше: модель чаще ставит удачный день выше неудачного. Brier
меньше — лучше: он штрафует за неверную и самоуверенную вероятность. После
20:00 T15 проверил CNYRUBF, связку CNYRUBF+USDRUBF и nonlinear boosting. Ни
один вариант не улучшил сильный T7B-control на screen-2024 одновременно по
обоим bootstrap-интервалам. Поэтому T16 не меняет вечернюю температуру.

Это полезный отрицательный результат: интерфейс получает новую «температуру»
только тогда, когда есть доказанное улучшение, а не просто более свежая свеча.

# Метрики ожидаемой выгоды

## MAE в базисных пунктах ЦБ: меньше — лучше

| Фаза | Горизонт | Новая модель | Контроль | Открытый 2025–2026 |
|---|---:|---:|---:|---:|
| 15:30 | h1 / h3 / h5 / h10 | 54,50 / 81,13 / 98,13 / 126,06 | 61,71 / 87,70 / 102,65 / 131,77 | 55,32 / 84,85 / 108,96 / 148,19 |
| after-publication | h3 / h5 / h10 / h20 | 56,65 / 85,91 / 132,68 / 197,08 | 93,80 / 113,06 / 148,78 / 206,96 | тот же открытый контур |
| 19:00 | среднее h3/5/10/20 | 122,74 | 123,55 | небольшой выигрыш |

Новый T15 обучает global Ridge на остатке базового after-publication прогноза и
использует совместное движение CNYRUBF и USDRUBF. На screen-2024 приняты только
семь комбинаций, где обе date-block bootstrap-границы улучшения ниже нуля:

| Время | Принятые горизонты | MAE T15 | MAE T7B | Δ MAE |
|---|---|---:|---:|---:|
| 20:00 | h3 | 53,98 | 58,08 | −4,10 |
| 21:00 | h3 / h5 | 53,72 / 83,00 | 58,08 / 87,88 | −4,36 / −4,87 |
| 22:00 | h3 / h5 | 53,95 / 82,09 | 58,08 / 87,88 | −4,13 / −5,79 |
| 23:00 | h3 / h5 | 53,14 / 80,85 | 58,08 / 87,88 | −4,93 / −7,03 |

На открытом 2025–2026 эффект меньше, но направление обычно сохраняется: h3
улучшается примерно на 0,06–1,90 б.п., h5 — на 0,21–1,61 б.п. Это не новый
независимый holdout, поэтому вывод — «устойчивый screen-кандидат», не production-
гарантия. h10/h20 не улучшились и остаются на контроле.

# Push и температура — разные продукты

## Непрерывный виджет

Показывается при каждом открытии: температура, выбранный горизонт, ожидаемые
б.п., «обновлено в», источник, свежесть и уверенность. Даже при высокой
температуре push может отсутствовать: экран отвечает пользователю сейчас, а
уведомление расходует ограниченный бюджет внимания.

## Редкий push AP37

| Метрика | h3 | h5 | h10 | h20 |
|---|---:|---:|---:|---:|
| adjusted lift | 2,429 | 2,509 | 2,479 | 2,525 |

Минимальная частота по валютам — 1,009 сигнала в неделю; максимум — два на
валюту в ISO-неделю. В h5 принято 695 решений, средняя частота 1,038, средняя
future-only выгода 133,73 б.п. Полный T16-контур сохраняет push-сигналы без
изменений: AMD/KGS/KZT/TJS/UZS = 142/139/138/139/137.

Lift отвечает «насколько выбранные моменты лучше случайного дня» и не является
метрикой калибровки виджета. Для температуры нужны Brier/AUC; для размера выгоды
— MAE; для push — lift, частота и max2/week. Одно красивое число не может честно
описать все три выхода.

# Что дало наибольший прирост

1. **Завершённый market-prefix вместо дневного close.** Это самый большой
   честный источник информации: утром AUC ограничен, к 15:30 он достигает 0,785.
2. **Роутинг по фазе и горизонту.** CNYRUBF подтверждён в 09:00 лишь для h1/h3;
   вечерние perpetual-свечи — лишь для magnitude h3/h5. Остальные головы не
   обновляются «за компанию».
3. **Раздельные вероятность и magnitude.** В T15 новые свечи не помогли Brier,
   но снизили MAE. Единая модель скрыла бы этот результат.
4. **Mature-only обучение и двухдневный embargo.** Калибратор и router весов
   видят только уже известные исходы.
5. **Пост-2022 адаптация.** Более свежему режиму разрешено влиять через causal
   training weights и признаки; год 2022 не используется как магическая граница,
   подобранная на будущем тесте.
6. **Явное provenance.** Вероятность и ожидаемые б.п. имеют отдельные
   `source_at`, age и freshness.

Сезонность, one-hot валюты и глобальное обучение полезны внутри ансамбля, но не
объявляются самостоятельным доказательством. 2025–2026 многократно открывался в
исследовании; следующий честный уровень уверенности — prospective shadow или
новый временной holdout.

# Как выглядит ответ API

## Поля, которые нужны интерфейсу

- `currency`, `horizon_publications`, `score_as_of`;
- `temperature_0_100`, `label`, `confidence`;
- `expected_future_cbr_bps_h`;
- `last_source_at`, `age_minutes`, `freshness`, `source_kind` — для вероятности;
- `benefit_last_source_at`, `benefit_age_minutes`, `benefit_freshness`,
  `benefit_source_kind` — отдельно для magnitude;
- `phase`, `availability_evidence`, `push_now`.

Пример вечернего состояния KZT, 01.09.2026: в 21:15 температура h5 остаётся
42,6 от последней подтверждённой probability-модели 20:00, а ожидаемая выгода
49,4 б.п. использует perpetual-prefix 20:59:59. Для h10 вечерняя Ridge не
принята, поэтому и magnitude остаётся на контроле.

На выходном система удерживает последний снимок, но увеличивает age и выставляет
`stale`. Пользователь видит отсутствие новых данных, а не искусственно движущийся
индикатор. Это также позволяет честно закрыть промежутки, где биржа не торгуется.

# Ограничения и следующий production-шаг

## Что уже можно показывать

- причинную температуру и ожидаемые б.п. для любой валюты/дня/поддержанного h;
- динамику внутри дня только от реально завершённых источников;
- редкий push отдельно от экранной оценки;
- источник, возраст, фазу и ограниченную уверенность fallback-состояний.

## Что ещё нельзя обещать

- фактическую рублёвую экономию: нет исполнимых банковских bid/ask, комиссии,
  лимитов и задержки исполнения;
- точный момент исторического переключения на новый курс ЦБ: receipt пока
  восстановлен календарно;
- независимую финальную оценку: открытые 2025–2026 использовались многократно.

Следующий шаг — подключить event timestamp публикации ЦБ и поток реальных
банковских котировок, запустить prospective shadow и мерить одновременно
калибровку температуры, ошибку expected bps и экономический uplift. Текущая
модель — сильный исследовательский прототип для интерфейса, а не обещание
исполнения по курсу ЦБ.
